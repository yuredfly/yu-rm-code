# 前哨站视觉任务参数

## 一、相机标定参数

```yaml
image_width: 1280
image_height: 1024
camera_matrix:
  rows: 3
  cols: 3
  data: [1781.053454, 0, 510.5751561,
         0, 1781.686873, 472.9735763,
         0, 0, 1]
distortion_model: plumb_bob
distortion_coefficients:
  rows: 1
  cols: 5
  data: [-0.04420740074, -0.1081537096,
         -0.0006506219039, 0.0002357380215, 0.466737247]
```

- 图像尺寸：1280 × 1024 像素。
- 相机矩阵 `K` 的形式为 `[[fx, 0, cx], [0, fy, cy], [0, 0, 1]]`。其中 `fx、fy` 是以像素为单位的焦距，`cx、cy` 是主点坐标。
- 畸变系数按 OpenCV 常见的五参数顺序 `[k1, k2, p1, p2, k3]` 使用。调用 `solvePnP` 或 `projectPoints` 时，将这组系数与 `K` 一起传入。
- 这组参数的标定平均重投影误差为 0.328514 px，仅作为标定结果的参考。
- 第二阶段使用原始 1280 × 1024 图像及对应像素坐标。若处理前缩放或裁切了图像，需要先将角点坐标换回原图坐标，或提供相应调整后的相机矩阵。

## 二、单块小装甲板的 PnP 模型

| 参数 | 数值 | 用途 |
| --- | ---: | --- |
| 模型宽度 `w` | 0.135 m（135 mm） | 建立装甲板四角的三维模型点 |
| 模型高度 `h` | 0.056 m（56 mm） | 建立装甲板四角的三维模型点 |

以装甲板中心为模型坐标系原点，四个模型点按以下顺序排列：

```text
0：左上 (-w/2, -h/2, 0)
1：右上 ( w/2, -h/2, 0)
2：右下 ( w/2,  h/2, 0)
3：左下 (-w/2,  h/2, 0)
```

模型坐标系的 `x` 轴沿装甲板宽度向右，`y` 轴沿高度向下；四点的 `z` 坐标均为 0。图像角点必须按同样的左上、右上、右下、左下顺序对应。长度统一使用米。

## 三、前哨站三板几何参数

| 参数 | 数值 | 含义 |
| --- | ---: | --- |
| 装甲板数量 | 3 | 前哨站模型中的装甲板总数 |
| 相邻板角度间隔 | 120°（`2π/3` rad） | 三块板均匀分布在旋转平面内 |
| 旋转半径 `R` | 0.275 m | 旋转中心到装甲板中心的水平距离 |
| 高度偏移集合 | 0、+0.102、−0.102 m | 三块板中心相对中间高度的偏移 |

可用下面的模型表示三块装甲板中心的位置：

```text
X_i(t) = center_x - R * cos(theta(t) + i * 2*pi/3)
Y_i(t) = center_y - R * sin(theta(t) + i * 2*pi/3)
Z_i(t) = center_z + height_offset[i]
```

这里的 `i` 是板编号，`height_offset` 取上述三个高度值。基础任务中板编号与高度的对应关系由任务说明给出；算法挑战若隐藏板编号，对应关系由参赛者根据观测处理。

## 四、坐标与使用范围

- 长度统一使用米，图像坐标及重投影误差使用像素，角度使用弧度（表格中特别标为度的除外）。
- 相机标定参数用于匹配视频的成像过程；前哨站几何参数用于描述三板模型，二者用途不同。
- 参数来源：相机参数由相机标定结果整理；装甲板尺寸和前哨站几何参数从现有工程模型中提取。
